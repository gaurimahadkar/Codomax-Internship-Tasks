# Inkspire — Responsive Blog Application

A responsive front-end blog application built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — Home page with sample stories and category filters
- `register.html` — Registration form
- `login.html` — Login form
- `dashboard.html` — User dashboard with create, edit and delete actions
- `create-blog.html` — Create/edit story form with image preview and word count

## Run locally
1. Extract the ZIP.
2. Open the `blog-application` folder in VS Code.
3. Install the **Live Server** extension.
4. Right-click `index.html` and choose **Open with Live Server**.

You can also open `index.html` directly in a browser, but Live Server is recommended.

## Demo storage note
This is a front-end demonstration. Accounts and stories are stored in browser `localStorage` on the same device/browser. Passwords are stored in plain text, so this is **not production-secure**. For a real deployment, connect Django/backend authentication and a database, and never store raw passwords in browser storage.

## Technologies
HTML5 · CSS3 · JavaScript · Google Fonts · localStorage
