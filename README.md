# Module 01 - Blog Application

## About the Project
The Blog Application is a responsive web application developed as part of Module 01 of my internship. It provides a simple and user-friendly platform to explore blog posts and manage blog content.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Responsive and attractive user interface
- Home page with blog posts
- Blog categories
- User-friendly navigation
- Login and Registration pages
- Blog content display
- Interactive frontend design

## Project Structure
```text
Module-01-Blog-Application/
├── index.html
├── login.html
├── register.html
├── dashboard.html
├── create-blog.html
├── css/
├── js/
└── images/
```

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Explore the application in your browser.
